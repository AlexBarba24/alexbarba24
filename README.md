## Dining Hall Mobile App
I am currently working on an application for the University of Michigan dining halls where students can rate different dishes served at the several dining halls on campus. Users will be able to view their past ratings and community ratings for different dishes to help them decide where to dine. 

This application was designed for IOS using a SwiftUI front-end with a flask API python backend, and a SQLite database for storing user ratings.

### Robotic Arm Control System (Michigan Mars Rover)

**Tech:** ROS2, C++, Python

Designed and implemented a modular ROS2 action server to convert user click inputs into robotic arm movements.

- Translated UI click inputs into arm-space coordinates using point cloud data
- Integrated coordinate frame transformations for accurate targeting
- Collaborated in a large multi-developer ROS2 codebase using Git workflows

**Impact:** Improved reliability and usability of operator-controlled arm movement in a complex robotics system.
